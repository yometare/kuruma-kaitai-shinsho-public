取り扱う情報

車両情報、ODO、給油・洗車・整備・費用・自由記録、日時・メモ、ユーザーが選択した写真や資料等を保存できます。

クラウド機能を利用する場合は、メールアドレス、ユーザーID、同期対象のMY CAR情報・記録・写真・資料、同期に必要な情報を取り扱う場合があります。

クラウドを利用しない場合、基本記録は端末内へ保存します。

利用目的

  • 愛車情報・履歴の保存と表示
  • ODO、費用、記録件数等の表示
  • ユーザーが選択した端末間での同期
  • 写真・資料の保存・復元
  • データ書き出しやRecovery Backup
  • アカウント認証、データ保護、同期競合の防止
  • 不具合調査、セキュリティ維持、サポート

外部サービス

クラウド機能にはSupabaseを利用します。開発環境とは分離したProduction環境を用意し、公開前の確認を進めています。

v1.0は広告なしで公開する方針です。2026年9月13日時点では、広告SDK・分析SDK・Crash reporting SDKに該当する依存は確認されていません。将来導入する場合は、本ポリシーとストア申告を更新します。

写真・カメラ

写真添付では、ユーザーが選択した写真または撮影した写真だけを対象とします。選択していない写真をMY CARへ自動登録する設計ではありません。

保存・削除

一部の通常削除データは、誤操作からの復元のため30日ごみ箱で扱う設計があります。Recovery Backupは同期とは別の復旧用データです。

アカウント削除は通常の30日ごみ箱とは別に処理し、Production環境でDatabase / Private Storage / Recovery Backup / Auth userの削除を検証済みです。アプリを利用できない場合のWeb削除依頼方法は Account deletionページ をご確認ください。

データ書き出し

自身のデータを書き出し、OS標準共有から保存・共有できる設計です。共有後の保存先サービスでの取扱いは、そのサービスの条件・ポリシーに従います。

セキュリティ

本人以外のMY CARデータへのアクセスを制限するため、アカウント単位のアクセス制御や非公開ストレージ等を利用する設計です。安全対策は継続的に見直します。

未提供の機能

v1.0では、GPS、OBD、COMMUNITY公開投稿、高度OCR / AI等は未提供またはComing Soonです。後続バージョンで提供する場合は、本ポリシーを更新します。
